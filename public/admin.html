    Setup walkthrough — open each, follow the steps, done. The checklist in section 01 turns green as you go.

    1 · Twitch auto-sync + LIVE badge (~5 min)
    1. Register an app at dev.twitch.tv/console/apps → Register Your Application. Name it anything, set the OAuth Redirect URL to , category Website Integration → Create. Copy the Client ID, then create + copy a Client Secret.
    2. Find your numeric broadcaster ID: open https://decapi.me/twitch/id/YOUR-TWITCH-NAME (swap in your name) — the number it returns is the ID.
    3. In the Railway dashboard (service → Variables tab) add: TWITCH_CLIENT_ID, TWITCH_CLIENT_SECRET, TWITCH_BROADCASTER_ID. (If TWITCH_EVENTSUB_SECRET is missing, add any random string.) Saving redeploys automatically.
    4. Back here, hit Connect Twitch above → authorize with your Twitch account → copy the TWITCH_REFRESH_TOKEN shown on screen into Railway Variables.
    5. Refresh this page — the Twitch rows go green. The LIVE badge and post-stream clip pulls now work.
    2 · YouTube auto-sync + new-video alerts (~7 min)
    1. In the Google Cloud Console create a project, then enable the YouTube Data API v3 (APIs & Services → Library).
    2. APIs & Services → OAuth consent screen → External → app name + your email → add the .../auth/youtube.readonly scope → add yourself as a test user.
    3. Credentials → Create Credentials → OAuth client ID → Web application → Authorized redirect URI: → copy the Client ID + Client Secret.
    4. Find your channel ID: it starts with UC — your channel URL or YouTube Settings → Advanced settings.
    5. In Railway Variables add: YOUTUBE_CLIENT_ID, YOUTUBE_CLIENT_SECRET, YOUTUBE_CHANNEL_ID.
    6. Back here, hit Connect YouTube → authorize with your Google account → copy the YOUTUBE_REFRESH_TOKEN into Railway Variables.
    7. Refresh this page — the YouTube rows go green. New uploads appear automatically.
    3 · Discord alerts (~2 min)
    1. In your Discord server: channel Settings → Integrations → Webhooks → New Webhook → Copy Webhook URL.
    2. In Railway Variables add it as DISCORD_WEBHOOK_URL.
    3. Hit Send Discord test in section 01 — the message should land in the channel. Going live and new YouTube uploads will post there too.
    4. Paste your server invite link in section 02 so followers can join.
    4 · Railway Variables + password
    1. Open the Railway project → your service → Variables tab → + New Variable → paste name + value. Every save redeploys by itself; then refresh this page.
    2. Change the default Admin password: set a new ADMIN_PASS (and ADMIN_USER if you like) in Variables. The checklist stops nagging once the defaults are gone.
    3. Rule of thumb: page content lives here in /admin, secrets live in Railway Variables. If a Connect button says "not configured", that variable is still empty.
